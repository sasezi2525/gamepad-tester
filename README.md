# Gamepad Tester v1.8

既存v1.7（https://sasezi2525.github.io/gamepad-tester/ の取得版）に電車でGO！表示を追加しました。Xbox・Switch・PS表示、数値表示、確認履歴、振動、ドリフト、入力の細かさ測定、PWAを引き継いでいます。

## GitHub Pagesへの配置

このフォルダー内の index.html / train.js / train-ui.js / sw.js / manifest.webmanifest / icon.svg を既存リポジトリの公開フォルダーへ上書きしてください。サブフォルダーでのPages公開にも対応します。ビルド作業は不要です。HTTPSで一度オンライン起動し、再読み込みするとオフラインで利用できます。新しいService Workerの導入後に画面のv1.8を確認してください。

## 電車コンの操作

- USB v0.8.1はXInput、BLE v0.5.2はBluetoothで接続してください。
- 本体の初期「自動」モードでは、専用データを検出して電車コン表示に切り替えます。名前だけでは判定しないため、通常のPS2コントローラーを誤認しません。
- 手動で「電車でGO！」を選ぶこともできます。自動に戻すには「自動判定」をオンにします。既存の「自動判定をずっとオフ」設定も利用できます。
- 表示は力行「切・P1〜P5」、ブレーキ「解除・B1〜B8・非常」。両ハンドルを同時に表示します。
- 本体が軸モードの場合は「軸出力モードの手動設定」で分離全軸・分離半軸・ワンハンドルを選び、必要に応じ軸番号と反転を設定してください。設定はブラウザに保存します。
- 本体モード切替はSELECT＋START約2秒。自動→分離全軸→分離半軸→ワンハンドル→自動。ワンハンドルはブレーキ優先のため同時の力行位置を復元できません。
- 非標準GamepadマッピングではA/B/C等のボタン番号が環境で異なる可能性があります。数値表示と併せて確認してください。リマップ済みの軸も手動調整が必要です。

## 検証と制限

専用データの全60組を、符号・軸順・32767/32768の正規化差を変えて検査しました。分離軸の全段数、異常コードの拒否、JavaScript構文、同梱ファイルを検査しています。ブラウザの画面確認・実機USB/BLE入力・オフライン再起動は未検証です。ブラウザがGamepad APIで機器を公開しない場合は読み取れません。Switch出力は今回の専用データ判定の対象外です。

動作確認：P0〜P5、解除〜B8・非常、A/B/C/SELECT/START、同時操作、切断・再接続、複数台の選択、通常パッドへの切替、ページ再読み込み、オフライン起動を確認してください。
