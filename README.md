USB v0.8.19 / Gamepad Tester v1.29
JETでGOの配置とスロットル軸変更

USB・テスター両方を更新してください。USBはfirmware/PS2-xinput-v0.8.19.uf2、テスターはGitHub PagesへZIP内容を上書きしてv1.29を確認。
JETの図を左=操縦桿、右=スロットルへ変更しました。文字は反転せず、各パーツの位置を移しています。
スロットル出力を右スティックXの中央〜右端から、右スティックYの下端〜上端の全範囲へ変更。
物理スロットル下限（実測byte6=253付近）=XInput RY -32767=Gamepad API Axis3 +1（下端）=テスター0%。
物理スロットル上限（実測byte6=10付近）=XInput RY +32767=Gamepad API Axis3 -1（上端）=テスター100%。
右Xは中央0へ固定。テスターでは(1-Axis3)/2で0〜100%を表示し、Y軸中央0は50%です。
旧版との軸割当互換はないため、USBとテスターは一緒に更新してください。OSによる軸補正は残ります。
L2/R2、JET識別安定化、単発通信エラー時の軸40ms未満保持、JET最短4ms＋通信後2ms休止、ほかのパッドの低遅延処理を維持。
その他→JETでGO！を手動選択する方式は維持。BT版は変更なし。

検証
USB全ソースビルド・UF2生成、スロットル244段階の単調性、右X中立、右Y両端、L2/R2をコンパイル時検査。
テスターの下端0%・中央50%・上端100%、操縦桿の左配置と従来機能の模擬入力、JS構文、ZIP整合性を検査。
実機での今回の軸動作・図の確認は未実施です。
