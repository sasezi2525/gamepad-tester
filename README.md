Gamepad Tester v1.20.2
未知コントローラー解析の操作名欄に、チェックボックス用20pxサイズが適用されて小さくなっていました。
チェックボックス限定のCSSに修正し、操作名は横幅いっぱいの48px高さ・16px文字で表示します。
○×□△、L1/R1/L2/R2、方向キーをタップして操作名を入力する補助ボタンを追加。直接文字入力も可能です。
①無操作の基準を記録→②操作名を入力／選択→③パッドを保持して3秒以上待ち「今の状態を記録」。パッド操作だけでは自動記録しません。
記録件数を表示し、0件の結果をコピーした場合は基準だけであることを案内します。
USB v0.8.11のまま使用してください。ファームウェアの更新は不要です。
