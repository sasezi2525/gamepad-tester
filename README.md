Gamepad Tester v1.11.1

ネジコン／ZEROTECHとアナログジョイスティックの全アナログ出力に、通常パッドのトリガーのような横バーを表示します。
・4つの軸は中央0から左右へ伸びるバー（マイナスは青、プラスは緑）。

・数値表示と目盛りを併記。未接続・未取得時はバーを空にします。
