Gamepad Tester v1.33

GitHub PagesへZIP内容を上書きし、v1.33表示を確認してください。ファーム更新は不要です。

ネジコン図を修正:
・STARTを左側の右端へ移動。
・AはB0、BはB2で点灯するよう修正。
・IとIIをボタン点灯から小型の縦バーへ変更。入力が増えると下から上へ伸びます。
・自動では右Yの負方向またはRTをI、右Yの正方向またはLTをIIとして表示。
・右Y合成／トリガー出力の明示選択と、I/II入替を追加。表示設定は保存します。

STD/STD交換はIとIIが右Yの差分で送られるため、両方同時押しの個別値は復元できません。バーは変換後の出力です。
DX/DX交換では出力がパルスになるため、連続した元の感圧値としては表示できません。デジタルモードではオン／オフです。
ゲームへの入力、ファーム、他機種の割当は変更していません。iPhoneでの実機確認は未実施です。
