USB v0.8.15 / Gamepad Tester v1.25
つりコンの通常ボタン出力修正

USBとテスターの両方を更新してください。USBはfirmware/PS2-xinput-v0.8.15.uf2、テスターはGitHub PagesへZIP内容を上書きします。
USB出力から常時R3マーカーを削除し、L2にセンサー値を載せる方式を廃止。
物理L2/R2は通常のLT/RTトリガー（0/255）として送ります。↑/→へ代用しません。
無操作の実測データで、ボタン・トリガー・各軸すべて0になることをコンパイル時検査しています。
PlayStation等の別表示モードを選んでも、USBのボタン出力自体が正しい状態になります。テスターの見た目だけで隠す修正ではありません。

つりコン画面
その他→つりコンを手動選択します。検出時の自動切替はしません。イラストは通常の表示位置。
左X/Yはスティック、右Xはリール反応（回転方向区別なし）、右Yは本体の動き3値から合成した強さです。
リール反応は動き始めを見やすくする拡大表示で、角度・回転数・正確な速度ではありません。OS補正を含む参考表示です。
ボタン用LT/RTを確保したため、通常モードでセンサー3値を個別転送することはできません。個別の生値はBOOT8秒の解析モードで従来どおり取得できます。
解析モードは専用の転送信号を送るため、通常ボタン出力とは異なります。ゲームを終了して使用してください。
旧USB版向け表示互換は維持していますが、他表示モードでの常時点灯をUSB出力から解消するにはv0.8.15へ更新してください。

低遅延
v0.8.14の最短2ms目標＋通信完了後最低1ms休止、受信失敗時4/8/20ms後退を維持。
PS2感圧初期化待機、HOME、保存設定、その他パッドを維持。つりコンの専用割当にはリマップを適用しません。BT版は変更なし。

検証
USB全体ビルド・UF2生成、無操作で全入力0、L2/R2同時押しでLT/RTのみ255、○押下にマーカーが混ざらないことを検査。
テスターの別表示でデータ無加工、専用図のL2/R2対応、新旧USB転送の読取、通常選択位置・既存機能の模擬入力、JS構文・ZIP整合性を検査。
iPhone実機での今回の出力・表示は未確認です。
