Gamepad Tester v1.21
未知コントローラー解析に「連続記録を開始」を追加。
基準と操作名を設定し、5／10／20秒（初期10秒）を選んで開始。3秒の準備時間後、記録中の完全な受信フレームを保存し自動終了します。
リールは記録中ずっと回してください。リール正回転／逆回転などを別々の名前で記録します。
画面には残り秒数とフレーム数を表示。「記録を終了」で途中終了も可能です。
開始前の状態が混ざらないよう、記録開始後最初の完成フレームは捨てます。
結果には連続記録samplesと各byteの最小・最大、基準から変化したビットを含めます。既存の単発記録も維持。
記録中は基準変更・リセット・コピーを止め、端末を他画面へ切替えた場合やUSB切断／選択機器変更時は部分記録を残して中断。
受信は約0.7〜1.9秒ごとのスナップショットです。高速の回転波形・連打・遅延を測る機能ではありません。時刻はブラウザで受信完了した相対時刻です。
USB v0.8.11をそのまま使用。テスターだけGitHub Pagesへ上書きし、v1.21を確認してください。
タイマー境界・準備中除外・重複除外・自動終了・中断・範囲集計、従来機能とUIの模擬入力・JS構文検査済み。iPhone実機は未確認。
