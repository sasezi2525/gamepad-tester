USB v0.8.16 / Gamepad Tester v1.26
つりコンのリール速度感を点滅で表示

USBとテスターの両方を更新してください。USBはfirmware/PS2-xinput-v0.8.16.uf2、テスターはGitHub PagesへZIP内容を上書きしてv1.26を確認。
従来の「リール値が0でなければ点灯」から、リール入力の強さに応じて約1.5〜12回/秒で点滅する表示へ変更しました。回すのを止めると消灯します。
点滅回数は表示上の演出で、実際の回転数やゲーム向けボタン連打を送る機能ではありません。方向は区別しません。
USBはbyte12の信号を200ms窓で集計。疎な反応は量を集計、連続した値は平均を使って、単純に読み取り回数を増やしただけで飽和しないようにしています。
回転の強さはOS補正を含む目安です。実機に合わせた速度範囲の検証はまだです。表示強度に上限があり、最速域は点滅上限へ達します。
集計に最大約200msの待ちが加わりますが、これはリール表示用の処理だけです。ボタン・スティックの低遅延読み取りは従来どおりです。
ボタン、通常L2/R2、R3常時オン廃止、つりコン手動選択、他表示モードでの正しい通常ボタン出力を維持。BT版は変更なし。
正確な生データは従来のBOOT8秒解析モードで取得できます。

検証
USB全ソースビルド・UF2生成。パルス頻度／連続値の大小で強度が変わること、1単位の小さな入力、タイマー周回、停止後の解除を検査。
点滅速度の大小、明暗両状態、停止・無効値での消灯、従来図・機種・診断機能の模擬テスト、JS構文とZIP整合性を検査。
iPhone実機・実際のリール速度との対応は未確認です。
