Gamepad Tester v1.19.1
感圧診断を「その他」の機種一覧から削除し、「設定 → PS2感圧診断を表示」に移しました。
設定を開いて表示をオンにすると、その下に診断バーを表示します。PlayStationの手動選択でも、自動判定でも利用できます。
感圧診断によって表示タイプを自動変更しません。前版の「感圧診断」を手動保存していた場合はPlayStationへ移行します。
このチェックはテスター側の表示だけです。変換器でSELECT＋START＋L1＋R1の4つだけを3秒押して診断送信を開始／終了してください。
USB v0.8.9 / BT v0.5.9はそのまま使用できます。ファームウェアの更新は不要。
表示タイプに関係なく専用信号を確認し、感圧データを復元します。信号がない場合は「診断信号なし」、感圧通信未成立は「未取得」です。
診断中はゲームを終了してください。診断用信号は通常のGamepad API経由で送られます。
