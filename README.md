Gamepad Tester v1.12.1
実機報告に基づき、PS用KONAMIドラムの初期配置を設定しました。
ハイハット B3 / スネア B1 / ハイタム B7 / ロータム B5 / シンバル B0 / バスペダル B6 / SELECT B8 / START B9。
↑ B12は常時オンの識別信号として状態を別表示し、初期配置の打撃表示・回数には含めません。
B12のみでは通常パッド等と一意に区別できないため自動判定は追加せず、「その他 → ドラム」で選択します。
従来の手動割当は保存したままです。新しい初期配置に戻すには「初期配置に戻す」を押してください。
USB v0.8.8の実機報告に基づく配置です。BT v0.5.8も標準変換の配置は同じですが、ドラム実機では未確認です。ファームウェアの書換えは不要です。
GitHub Pagesの公開フォルダーへZIP内ファイルを上書きし、再読み込み後v1.12.1を確認してください。
構文・模擬入力による配置、常時B12、回数、割当、切断表示を検査。実ブラウザ・実機での更新版検証は未実施。
