USB v0.8.13 / Gamepad Tester v1.23
つりコンの通常Gamepad APIリアルタイム表示

USBファームとテスターの両方を更新してください。USBはfirmware/PS2-xinput-v0.8.13.uf2、テスターはGitHub PagesへZIP内容を上書きします。
つりコンを接続すると自動的につりコン用Gamepad入力へ入り、約20ms間隔で読み取ります。BOOT操作は不要です。
テスターの機種名が汎用のXbox等になって自動判定されない場合は、「その他 → つりコン」を手動選択してください。
ボタン・スティック・リールが通常のGamepad APIを通して表示され、旧版の約0.9秒の分割完了待ちは不要です。画面更新・通信・OSを含めた総遅延が20msという意味ではありません。

割当
□△○×、L1/R1、SELECT/START、スティック押込は通常の論理ボタン。
L2/R2は専用表示用に十字キー上／右へ割当（同時押しも区別）。未使用R3はつりコンライブ信号。
左X/Y=スティック（中心146/128を基準）、右X/Y=センサー1/2、LT=センサー3、RT=リール。
図は元の物理ボタン名へ戻して点灯し、リールは回転方向を区別しません。
スティックとセンサー1/2の画面数値は、OS補正された軸から換算する参考値です。正確な生値・センサーの詳細解析はBOOT8秒の従来解析モードを使ってください。
通常Gamepad向けの専用割当なので、ゲーム側の既定操作とは一致しない場合があります。センサー3がLTを使う点にも注意してください。
Switch出力保存時もつりコンではXInputへ一時再接続。保存形式・ほかのコントローラー・感圧診断・HOMEを維持。BT版は変更なし。
つりコンのライブ転送では専用割当を保つため既存リマップを適用しません。従来のその他パッドのリマップは維持。

検証
USB全体ビルド・UF2生成、11物理ボタンの対応、L2/R2同時押し、スティック端点と中心、リール／センサーの転送を検査。
テスターの通常名／汎用名手動選択、リアルタイム図点灯、旧生データ表示と既存各機種・診断機能の模擬入力、JS構文とZIP整合性を検査。
