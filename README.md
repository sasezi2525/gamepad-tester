Gamepad Tester v1.14
写真を元にKONAMIギターの簡略図を追加。赤・緑・青、ピック、SELECT/STARTが入力に連動します。
ウェイリングは物理ボタンと区別して「傾ける」状態表示にしています。
「正面」（ネックが右）／「抱えて上から」（ネックが左、奥行きを圧縮した模式図）を切り替えられます。
角度設定はこの端末のブラウザに保存。両方の角度とも同じ保存済み割当・120ms点灯保持に連動します。
初期配置はユーザー実機確認済みの赤B7・緑B1・青B3・ピックB12・ウェイリングB6・SELECT B8・START B9。
ドラム図、コントローラー選択の上側固定、以前の設定を維持。変換器の更新は不要です。
GitHub Pagesの公開ファイルをZIP内容で上書きして再読込し、v1.14を確認してください。
JS構文・模擬入力・角度切替・設定保存・切断時消灯を検査。実ブラウザ画面と実機での更新版確認は未実施。
