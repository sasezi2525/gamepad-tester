USB v0.8.12 / Gamepad Tester v1.22.1
SLPH-00100つりコンの専用テスト自動モード

使い方
USBをfirmware/PS2-xinput-v0.8.12.uf2へ更新し、テスターをGitHub Pagesへ上書きしてv1.22.1を確認します。
つりコンを接続するとID E5/HEADER5Aを判別し、自動で専用テストデータの送信へ入ります。BOOTの8秒操作は不要。
テスターはつりコン専用図を自動表示。図の点灯、スティック、回転方向を区別しないリール反応、センサー3値を確認できます。
未表示ならテスターを開き直し、完全な受信フレームが揃うまで数秒待ってください。
つりコンを外して別のパッドを挿すと、3回連続の非つりコン応答後に通常処理へ戻ります。
更新周期は従来と同じ約0.9秒です。短い押下は保持して確認してください。専用ゲームへの通常入力を追加する更新ではなく、テスター用の生データ転送です。

互換性
感圧診断、専用HOME、リマップ、その他のコントローラー、未知解析を維持。保存設定形式は変更しません。BT版は変更なし。
つりコンにはDualShock用の自動設定や振動命令を送りません。
Switch出力が保存されていても、つりコン検出時には一時的にXInputへ再接続します。保存設定は変更せず、通常のパッドで電源再投入すれば保存した出力へ戻ります。
つりコン専用テスト中は通常ゲームの出力ではありません。ゲームを終了して使用してください。
つりコンテスト中にBOOTを短く押すと再起動し、接続したままなら再び自動テストへ入ります。終了はつりコンを外します。
BOOT8秒で汎用の未知解析モードへ入る操作も維持しています。

検査
USB全体ビルド・UF2生成、13バイト受信・ヘッダー・起動時判別・感圧モード誤選択の除外・DualShock設定除外をコンパイル時検査。
テスターの実測ボタン、軸端点、中心設定、リール、未取得表示と既存機能の模擬テスト・JS構文を検査。
実機・iPhone上での今回の自動認識は未確認です。
